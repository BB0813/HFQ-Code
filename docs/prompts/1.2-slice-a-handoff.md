## 3. 本刀范围

### 3.1 In（必须做完才算 Slice A 完成）

#### U1 · 设计系统（FE）

路径：`apps/desktop/renderer/src/index.css` · `components/ui/*` · 必要的 tailwind 扩展。

1. **tokens 收口**：surface-1/2/3、panel、activitybar、border、muted、workbench 强调色（克制）；与 dark 主题一致。  
2. **字体**：保留/完善已有 `--font-ui` / `--font-mono`；标题/正文/标注层级可读。  
3. **密度**：列表行、tab、图标按钮高度体系统一（优先 `h-7`/`h-8` 一档，勿一页一个高度）。  
4. **组件**：Button / Input / Badge / EmptyState / 必要时 Page 标题条 — **统一**，消灭明显「拼盘感」。  
5. **动效**：抽屉/侧栏开合 **短** transition（约 150–200ms）；禁大面积无意义动画。  
6. **不要**新增大依赖（无 framer-motion 等，除非仓库已有且必要）。

#### U2 · 壳层（FE · 核心缺口）

路径：`components/shell/*` · `store/ui-store.ts`。

| 组件 | 要做 |
|------|------|
| **ActivityBar** | active/hover 清晰；tooltip **中文**；路由 + drawer tab 逻辑保持 |
| **SessionSideBar** | 列表密度、当前会话、新建/空态；折叠行为保持（Ctrl+B） |
| **AppHeader** | 工作区/模型/权限/抽屉开关信息层级干净 |
| **RightDrawer** | tabs 文案与 active 态；宽度拖拽**保持**（现有 ui-store 即可，**本刀不必**上 config prefs） |
| **StatusBar** | 版本/路径/statusLine；不堆杂讯 |
| **CommandPalette** | 中文 label；高频：新建会话、终端、改动、设置、切换抽屉 tab |
| **AppShell** | 窄屏：先收抽屉再收侧栏；中心 Chat 保命；**不改**列结构为 B/D |

验收口吻：截图级「整壳换代」，不是只改 Chat 背景。
