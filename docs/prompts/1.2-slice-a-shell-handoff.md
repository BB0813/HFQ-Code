## 2. 本刀 In（按优先级）

### P0 · AppHeader（必须可感知）

路径：`apps/desktop/renderer/src/components/shell/AppHeader.tsx`

**问题（1.1.9 遗留感）**：标题区 / 权限 chip / 模型 / 抽屉按钮信息层级偏平；`running` 等英文 badge；控件高度不完全统一。

**要做（示例方向，可 refinement，但必须肉眼可见）**：

1. **信息层级**：左（侧栏开关 + 标题 + 工作区路径）/ 右（profile · 权限 · 模型 · 命令面板 · 抽屉）分区清晰；窄宽下合理折叠（已有 `sm:` 可加强，勿挤爆）。  
2. **密度**：工具按钮统一一档（优先 `h-7`，与 IDE 紧凑一致）；去掉明显「一块一块拼盘」的 border 堆叠感。  
3. **中文**：`running` → **运行中**（或与 StatusBar 统一文案）；title/aria 保持中文。  
4. **token**：背景/边框与 `surface-*` / workbench 一致；active 抽屉/侧栏按钮态可读。  
5. **行为不回归**：权限模式切换、abort、打开工作区、命令面板、toggle 抽屉/侧栏逻辑保持。

**验收**：并排想象 1.1.9 顶栏 vs 现在 — 非工程师也应看出「顶栏换代了」。

### P0 · StatusBar（必须可感知）

路径：`apps/desktop/renderer/src/components/shell/StatusBar.tsx`

**问题**：`running` / `idle` / `dirty` / `clean` 英文；分段与 hover 态一般；与 1.2 Chat/SideBar 的 workbench 语言未对齐。

**要做**：

1. **中文状态**：运行中/空闲；git 脏/干净（或保留 branch 英文名 + 中文状态词）。  
2. **分区**：左（产品·版本·git·运行态）| 中或次（模型）| 右（工作区路径）— 分隔与 `opacity`/hover 统一。  
3. **可点控件**：git → 改动、模型 → `/models`、路径 → openWorkspace、HFQ Code → 命令面板 — **行为保持**。  
4. **密度**：维持 `h-6` 量级或略调，但文字/间距与 Header 同属 1.2 体系。

**验收**：状态栏截图能读出「中文 IDE 底栏」，不是英文 debug 条。

### P0 · ActivityBar（必须可感知 · 超出 stroke 微调）

路径：`apps/desktop/renderer/src/components/shell/ActivityBar.tsx`

**问题**：主页 Bot 钮仍是 **高对比 zinc 白块**，与 rail 其它 `workbench` active 不统一；整体仍像 1.1.x。

**要做**：

1. **主页钮与 rail 体系统一**（去掉「突然一块白徽章」的营销/拼盘感；active/inactive 与 PRIMARY 同一语言）。  
2. **active 态**：左侧 rail 条 + 背景在 1.2 下更干净（可保留 workbench，但整体更 IDE）。  
3. **尺寸**：`h-10`/`w-10` 与 `w-11` 栏宽再收一档亦可，但 **必须有布局级可见变化**，不是只改 `strokeWidth`。  
4. **tooltip/菜单**：中文保持；More 菜单项密度与 1.2 列表一致。

**验收**：活动栏截图 vs 1.1.9 有「换皮」感，而不是「细看才发现 stroke 一样」。
