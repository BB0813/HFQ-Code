## 4. 前端实现规格（主责 · `apps/desktop/renderer`）

### 4.1 关键路径（现有）

```text
components/shell/
  AppShell.tsx · ActivityBar.tsx · SessionSideBar.tsx · AppHeader.tsx
  RightDrawer.tsx · StatusBar.tsx · CommandPalette.tsx · PanelResizeHandle.tsx
features/chat/ · features/terminal/ · features/changes/ · features/tasks/
pages/* · store/* · components/ui/* · index.css / tailwind
```

### 4.2 U1 · 设计系统

1. 收敛 CSS 变量：`--background` / `--panel` / `--panel-elevated` / `--activitybar` / border / muted / workbench 强调色（**克制**，非霓虹紫）。  
2. 字体：UI 无衬线 + 代码 mono（已有 JetBrains/Cascadia 可保留）；标题/正文/标注三级清晰。  
3. 间距：紧凑档（列表行、tab、按钮 `h-7`/`h-8` 体系一致）。  
4. 组件：Button / Input / Badge / EmptyState / PageScaffold **统一**，消灭一页一个风格。  
5. 动效：面板开合、抽屉 **短** transition（150–200ms）；禁大面积无意义动画。  
6. **不要**引入重型动画库除非已有依赖且必要。

### 4.3 U2 · 壳层

1. **ActivityBar**：图标可辨、active 态、tooltip 中文；路由 + 可选 `setDrawerTab` 逻辑保持。  
2. **SessionSideBar**：会话列表密度、当前会话、新建/空态；窄屏可折叠（沿用/强化 Ctrl+B）。  
3. **AppHeader**：工作区路径、模型/权限入口、抽屉开关；减少杂乱。  
4. **RightDrawer**：tabs `changes | terminal | tasks`；宽度拖拽记忆（接 F2-5）；关闭不丢 PTY（1.1.9）。  
5. **StatusBar**：版本、workspace、简短 statusLine；不堆广告。  
6. **窄屏**：优先收抽屉 → 再收侧栏；中心 Chat 保命。  
7. **CommandPalette (Ctrl+K)**：补齐高频命令（新建会话、开终端、改动、设置、切换抽屉 tab）；中文 label。

### 4.4 U3 · Chat

1. 消息时间线：更清晰的 user/assistant 区分（**非**微信气泡 IM 化）。  
2. 工具调用卡：可折叠、状态色、错误可读。  
3. Composer：粘性底栏、附件/模式入口不挤爆；`composerDraft` 消费逻辑 **保留**。  
4. 空态：绑定 workspace / 选模型 / 快捷 chip（可沿用并美化）。  
5. Markdown/mermaid：不回归 1.1.5 能力。  
6. 虚拟列表：**可选**；若做须防 scroll 跳变，做不完可延后但须在交付注明。

### 4.5 U4 · 编码三页版式

| 页 | 版式目标 | 行为红线 |
|----|----------|----------|
| Terminal | tab 条 + 工具条更清晰；空态 | reattach / 不误杀 / workspace 清列表 |
| Changes | 文件列表 + diff + commit 区层级 | j/k · stage/commit · ask agent 预填 |
| Tasks | goal 树视觉层级 · spawn 失败区 | parentStack · 孤儿顶层 · errorCode 中文 |

### 4.6 U5 · 次级页

- `PageScaffold` 标题/描述/主操作统一。  
- Settings：更新卡片（L1–L3）**功能不删**；分组间距统一。  
- Skills / Memory / Models / MCP / Usage / Permissions / Audit：同一套列表/空态/危险按钮样式。  
- Memory 页：为 F2-4 搜索框与结果列表留稳位点（可与 Slice C 同做）。

### 4.7 FE 非目标

- 不改 `electron/main.cjs` 业务除非 F2 需要（优先让 BE 加 IPC）。  
- 不删除 1.1.9 Terminal scrollback 逻辑。

## 5. 后端实现规格（F2 与小 prefs · `packages/*` + desktop electron）

### 5.1 原则

- **Slice A/B 默认零 BE**；仅当 panel prefs 要持久化时改 `prefs` schema（additive）。  
- Slice C 才允许 Memory/Goal 有意义 BE。  
- 一切新 IPC：**additive**、中文错误、写 `docs/FRONTEND-IPC.md`。  
- path-escape / workspace 边界不放宽。

### 5.2 F2-5 · Panel prefs（小）

建议形状（可微调，保持 backward compatible）：

```ts
// prefs.uiLayout? or prefs.panelPrefs
{
  drawerOpen?: boolean;
  drawerTab?: "changes" | "terminal" | "tasks";
  drawerWidth?: number;      // clamp e.g. 280..720
  sidebarOpen?: boolean;
  sidebarWidth?: number;
}
```

- `getConfig` / `setPrefs` 已有则复用。  
- FE 启动 hydrate；变更 debounce 写回。  
- 非法值 clamp；缺省 = 当前 1.1.9 默认行为。

### 5.3 F2-4 · Memory 可检索

**目标**：用户在 Memory UI（及可选命令面板）能 **快速搜到笔记**，不必全表扫到卡顿。

**推荐实现（按环境降级）**：

1. **主路径**：JSON 笔记旁路 **倒排索引**（如 `index.v1.json`）双写；search 走 index。  
2. **可选加速**：detect 可用时 Node sqlite **FTS5**；不可用 **不得**让 CI/运行红死，回退 1。  
3. 保留文件脑导出/可读性；不强制 Obsidian 兼容。  
4. IPC 示例（名称可对齐现有 memory API）：  
   - `memory:search` `{ query, limit }` → `{ hits: [{ id, title, snippet, score }] }`  
   - 索引重建：`memory:reindex`（设置里可手动）  
5. 单测：索引增删改后 search 命中；损坏 index 可重建。

**不要**：上 embeddings / 向量库（Track E）。

### 5.4 F2-Goal · Goal 轻量产品化

**已有**：1.1.6 `*.goals.json` sidecar · `parentTaskId` · driver 字段 · Tasks UI 基础树。

**本 train 加**：

| BE | FE |
|----|-----|
| 保证多级 parent 持久化与 `task.updated` 字段完整（progress/blockedReason/status/kind） | 树可视化（多级缩进或可展开） |
| list goals API 若分散则收敛为稳定列表（可复用 tasks 流） | 顶栏/Tasks 显示阻塞与进度 |
| 不引入第二数据库产品 | 不建「目标社交」或多人协作 |

**不要**：Athena 多租户 Goal OS 原样搬运。

### 5.5 明确不动（BE）

- agent-core 主循环大翻写  
- 更新管道 L0–L3  
- provider 协议重写  
- `@hfq/pty` reattach 契约（可修 bug，不删 ring）
